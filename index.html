ERP-ZS Release Control: safe releases, backups and rollback in one place

A web control panel I built to take ERP-ZS from development to UAT and then production safely. It shows all three environments side by side, runs releases as tracked jobs, keeps backups labelled by version, rolls back in one guided step, and records who did what.

3environments: Dev · UAT · Prod
SHA-256checked at every copy
1-stepguided rollback
Development main→Build package vX.Y.Z→UAT backup · migrate · health check→Git tag + release notes→Production prepare, check, release↺Rollback

What it does

  • Release to UAT: refuses to run unless the code is on a clean, pushed main. It builds a versioned package, backs up code and database, applies migrations, restarts, and waits for a health check before tagging the version in git.
  • Promote to production: only packages that passed UAT can be released, and each file is verified by SHA-256 at every copy. A no-downtime "prepare and check" step runs first, then a typed confirmation. If a step fails, the old version is restored automatically.
  • Rollback: code-only, or code and database. It only offers database dumps proven to match the target version's schema, and takes a safety dump before any restore.
  • Versioning: semantic versions, with release notes drafted automatically from conventional commits and a suggested version bump.

Engineering

  • A FastAPI backend runs the existing, tested PowerShell release tooling on Windows servers as tracked jobs, with live logs, one job at a time, and an audit trail.
  • A React front end with pages for the environment overview, releases, backups, live server logs, jobs and the audit trail.
  • Security: the admin password is stored only as a hash, server logins stay in encrypted per-user files (never in the repo or .env), and the panel checks each server's identity before changing anything. When hosted, it runs behind IIS with HTTPS and Windows Authentication.
  • Tests with pytest, Vitest and PowerShell scripts; it runs as a Windows service and can update itself.
